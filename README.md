# R-CORE client document site

Клиентский сайт для просмотра и подписания документов автопроката. Клиенты
переходят по ссылке из CRM к договору, акту, согласию или дополнительному
соглашению.

Новая версия на React/Vite находится в [frontend](./frontend). Она собирается
в статические файлы и может размещаться на Nginx, Caddy или другом веб-сервере;
данные пока остаются в Supabase. Инструкции по запуску и развёртыванию описаны в
[frontend/README.md](./frontend/README.md).

Исходный Flutter-проект пока сохранён в `lib`, `web`, `android` и `ios` на время
миграции. Новая версия ещё не заменяет весь процесс подписания: генераторы PDF и
часть действий, связанных с регистрацией подписания, предстоит перенести.
